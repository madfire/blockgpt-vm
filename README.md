# BlockGPT VM

BlockGPT VM is the runtime core behind BlockGPT graphical programming and hardware execution.

It extends the Scratch VM direction with BlockGPT-specific AI, hardware, upload, and extension behaviors.

## Responsibilities

- block execution runtime
- extension registration and dispatch
- hardware peripheral integration
- upload pipelines for Arduino and MicroPython workflows
- runtime support for BlockGPT-specific extensions

## Product role

Within the BlockGPT stack, this repository is the execution engine that turns generated or edited graphical programs into real behavior on stage and on connected devices.
